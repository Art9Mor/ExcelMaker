# ExcelMaker (EM Spec Generator)

Утилита на Python для автоматической обработки Excel-файлов (`.xlsm`/`.xlsx`) и генерации технической спецификации по данным первого листа. Поддерживает экспорт в Excel (`.xlsx`) и Word (`.docx`).

## Возможности

- 📊 **Парсинг Excel** — автоматическое определение структуры и колонок
- 📄 **Экспорт в Word** — создание профессионально оформленной спецификации
- 🖥️ **Графический интерфейс** — удобный drag-and-drop интерфейс на PyQt6
- ⌨️ **CLI режим** — для автоматизации и пакетной обработки
- 🔧 **Универсальность** — работает с любыми Excel-файлами, независимо от структуры
- 📝 **Поддержка переносов строк** — корректное отображение многострочного текста
- 🎨 **Профессиональное форматирование** — границы, выравнивание, автоширина колонок

## Запуск и использование

### CLI режим

CLI режим доступен из терминала. Следует передавать путь к файлу обработки и путь, куда сохранится результат (опционально[...]).   
Пример: 

```bash
  python main.py --cli <путь_к_файлу.xlsm> [--output <путь_к_результату>]
```

### GUI режим

GUI режим запускается после сборки путём двойного нажатия по исполняемому файлу (ExcelMaker.exe / ExcelMaker).   

#### Как использовать:

1) Нажмите «Выбрать файл» или перетащите .xlsm/.xlsx файл в область DropZone.
2) Выберите нужные форматы вывода (Excel и/или Word).
3) При необходимости выберите папку для сохранения результата.
4) Нажмите "Сгенерировать".
5) Готово! Файлы будут сохранены рядом с исходным (или в выбранной папке)

## Сборка

Сборка проекта осуществляется после исполнения скрипта *build.py*,   
после чего исполняемый (ExcelMaker.exe) файл можно будет найти в корне проекта, в директории *output*.   
Команда для сборки:

```bash
  python .scripts/build.py
```

## Конфигурации

Основные настройки находятся в src/core/writer.py и src/core/parser.py:

```

    "sheet_name": "Спецификация",
    "headers": ['№ п/п', 'Наименование', 'Ед. изм.', 'Кол-во', 'Сумма, руб'],

```

## Тесты

Проект покрыт теставми на pytest, которые можно запустить одной командой:

```bash
  pytest tests/ -v
```

Либо по-отдельности:

```bash
  pytest tests/test_models.py -v
```
